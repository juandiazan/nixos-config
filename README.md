# nixos-config

Should have the following categories:

- base -> includes:
  - base system configuration (boot settings, audio, network, users, etc)
  - desktop environment/window manager, status bar, notifications, gtk, etc
  - the usual programs (desktop apps, CLI tools, TUI's)
  - shell (shell program, plugins and aliases)

- cds -> includes:
  - tools for ripping cds
  - tools for burning cds

- dev -> includes:
  - CLI dev tools (aws, terraform, gh, dotnet, dotenv)
  - IDE's (vscodium, jetbrains rider, etc)

- gaming -> includes:
  - steam and necessary tools to run games correctly
  - drivers for GPU's
